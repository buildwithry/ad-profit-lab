# Ad Profit Lab — Design System

Reference: Dovetail — "Blueprint grid under a black moon"
https://styles.refero.design/style/108e2695-6970-47d5-b5b0-eea8fc34e048

## Direction

A compact, technical campaign command center. Near-black surfaces, quiet borders,
white typography, and one soft-indigo signal color. Depth comes from luminance and
borders, never shadows.

## Tokens

- Canvas: `#0a0a0a`
- Card: `#141414`
- Elevated: `#1e1e1e`
- Border: `#313131`
- Muted border: `#454545`
- Secondary text: `#a7a7a7`
- Primary text: `#ffffff`
- Accent: `#6798ff`
- Primary font: Inter, with system sans-serif fallback
- Metadata font: JetBrains Mono, with system monospace fallback
- Base spacing: 8px
- Card/input/button radius: 8px
- Max width: 1200px

## Rules

- Use indigo only for interactive state, charts, and small status marks.
- Use white-filled buttons for the strongest action; ghost buttons for secondary actions.
- Use 1px borders and stepped dark surfaces instead of shadows.
- Keep labels uppercase, small, monospaced, and tracked out.
- Keep body copy left-aligned and the dashboard information-dense.
